# 🍔 Burger Code

Application web CRUD de gestion de menus développée dans le cadre d'une formation Udemy en développement web.

Ce projet a été réalisé comme exercice pratique afin de mettre en application les notions de développement web dynamique avec PHP et MySQL.

---

## 📌 Description du projet

Burger Code est une application web permettant de gérer un catalogue de produits alimentaires avec une interface d'administration.

Le projet met en pratique :
- la création d'une interface utilisateur ;
- la gestion des données avec une base MySQL ;
- les opérations CRUD (Créer, Lire, Modifier, Supprimer).

Projet réalisé à des fins d'apprentissage et adapté dans le cadre de mon parcours de développeur web.

---

## 🚀 Fonctionnalités

### Interface utilisateur
- Affichage des produits.
- Présentation des burgers avec images et informations.

### Interface administrateur
- Ajouter un produit.
- Consulter les produits.
- Modifier un produit.
- Supprimer un produit.
